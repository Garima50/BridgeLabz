# REALITY CHECK

Most students:

* memorize solutions,
* cannot explain complexity,
* fail when question wording changes slightly.

You should practice like this:

1. Solve brute force first
2. Optimize yourself
3. Explain time complexity aloud
4. Re-solve after 3 days without hints

That’s how interview-level problem solving actually develops.

For placements, if you complete:

* ~120–150 *quality* questions
* with full understanding,
  you’ll already be ahead of most candidates.
